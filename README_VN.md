Trong quá trình làm việc, tôi đã đóng góp **150+ merge requests** và đạt được những kết quả sau:

### 📌 Tích hợp hệ thống phức tạp
- **Tích hợp 6+ nhà cung cấp dịch vụ** (Viettel, MISA, VNPT, EasyInvoice, Mobifone, FPT) thông qua RESTful API, xử lý **1000+ giao dịch/ngày**
- Xây dựng hệ thống đẩy dữ liệu sang **MSSQL Server** cho khách hàng doanh nghiệp, đảm bảo đồng bộ thời gian thực
- Thiết kế API cho đối tác với **Swagger documentation** đầy đủ

### 📌 Xử lý dữ liệu thời gian thực
- Phát triển luồng xử lý giao dịch: **Thiết bị → Gateway → Kafka → Backend**, xử lý **hàng nghìn giao dịch/ngày**
- Implement Kafka consumer đảm bảo **zero data loss** và xử lý chính xác một lần (exactly-once)

### 📌 IoT & Thiết bị thông minh
- Lập trình giao thức **UDP** kết nối với trụ bơm và thiết bị QR
- Xử lý và vận hành hệ thống trên **Raspberry Pi**, viết script tự động cập nhật code cho **50+ thiết bị**

### 📌 Tối ưu hiệu năng
- Tối ưu các truy vấn SQL phức tạp, **giảm thời gian xử lý báo cáo từ 5 phút xuống 30 giây**
- Phát hiện và xử lý **các lỗi nghiêm trọng về toàn vẹn dữ liệu**, đảm bảo độ chính xác 100%

### 📌 DevOps & Tự động hóa
- Thiết lập **CI/CD pipeline** với GitLab CI/Jenkins, tự động hóa quy trình deploy
- Containerize ứng dụng với **Docker**, triển khai **MinIO** cho lưu trữ file phân tán
